# 🛒 Blinkit Sales & Customer Insights Dashboard

## 📌 Project Overview

This project is a professional Power BI dashboard developed using a Blinkit retail dataset. The dashboard provides business insights into sales, profitability, customer satisfaction, delivery performance, and inventory trends. It demonstrates the complete data analytics workflow, from data preparation to interactive dashboard creation.

---

## 🎯 Objectives

- Analyze overall business performance
- Identify top-performing products and categories
- Compare brand and city-wise sales
- Monitor delivery performance
- Track customer ratings
- Support business decision-making through interactive dashboards
